System Architecture

Project Methodology & Scientific Foundation

Full-Stack Heart Disease Prediction Utilizing a Heterogeneous Stacking Ensemble with Resampling and Dimensionality Reduction.

1. Problem Statement & Motivation

Cardiovascular diseases (CVDs) remain the leading cause of global mortality, accounting for approximately 17.9 million lives each year. Early detection of individuals with elevated cardiac risk allows for timely lifestyle modifications, pharmacological interventions, and diagnostic surveillance.

Standard medical diagnostics require comprehensive multi-modal examinations. Conventional clinical scoring systems frequently employ linear assumptions that struggle to model non-linear physiological interactions between resting hemodynamics, exercise stress responses, and vessel obstruction. Machine learning presents an opportunity to capture these complex relationships, provided that class imbalance and data leakage are strictly prevented.

2. Project Objectives

  • Automated Clinical Input Validation: Enforce strict range, category, and type validation on both frontend and backend for all 13 UCI features.
  • Heterogeneous Stacking Architecture: Combine diverse base models (Logistic Regression, Random Forest, SVM) with an out-of-fold cross-validated meta-estimator.
  • Class Balancing Benchmark: Compare baseline performance against Synthetic Minority Over-sampling Technique (SMOTE), Random Undersampling, and Cost-Sensitive Weighting without test set contamination.
  • Dimensionality Reduction Evaluation: Empirically evaluate Principal Component Analysis (PCA) and ANOVA F-score feature selection against full-feature baselines.
  • Secure Cloud Persistence: Store user accounts with Werkzeug password hashing and isolate prediction history using MongoDB Atlas.

3. Machine Learning Methodology

Data Preprocessing & Leakage Prevention

The pipeline employs a strict scikit-learn ColumnTransformer. Continuous numeric variables (Age, Blood Pressure, Cholesterol, Max Heart Rate, and Oldpeak ST depression) are imputed via median strategy and scaled via StandardScaler. Categorical variables are one-hot encoded with handle_unknown='ignore'. Crucially, all transformers are fitted exclusively on training splits.

Stacking Ensemble Mechanics

The ensemble integrates three distinct inductive biases:

  • Logistic Regression: Provides linear decision boundaries with calibrated posterior log-odds.
  • Random Forest: Provides non-linear orthogonal splits robust to feature collinearity and outliers.
  • Support Vector Machine (RBF Kernel): Projects features into high-dimensional Hilbert space for non-linear margin maximization.

During training, 5-fold cross-validated out-of-fold predicted probabilities from base estimators form the feature matrix for the final Logistic Regression meta-learner, completely preventing information leakage.

Class Balancing Comparison

To address minority-class sensitivity, the training harness evaluates SMOTE oversampling, Random Undersampling, and Cost-Sensitive Class Weighting. Resamplers are embedded in imblearn.pipeline.Pipeline to guarantee that synthetic samples are generated solely within training folds.

5. Limitations & Medical Disclaimer

Small Dataset Cohort: The UCI Cleveland heart disease dataset contains 303 patient records collected at a specific clinical institution. While historically significant and extensively researched, models trained on small cohorts may experience reduced generalizability across broader, ethnically diverse patient populations.

Statistical Association vs. Clinical Causation: Permutation importances and model weights represent mathematical correlations in the sample distribution. They do not demonstrate physiological causation.

This system must never be used as a standalone diagnostic tool or as a substitute for professional medical consultation.
